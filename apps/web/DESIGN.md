# Xenia product design system (`apps/web`)

Pinned visual world for the product app (not the subgraph demo site).

## Tokens

| Token | Value | Use |
|---|---|---|
| `--ink` | `#1C1B16` | Primary text, dark CTAs |
| `--stone` | `#DCD7C9` | Page background |
| `--surface` | `#F2EFE6` | Cards / standing-check shell |
| `--olive` | `#5C6644` | Primary accent, good standing |
| `--olive-deep` | `#3E4530` | Large score numbers |
| `--bronze` | `#A6702E` | Money values only |
| `--clay` | `#8C3D2B` | Slash / default states only |
| `--border` | `rgba(28,27,22,0.14)` | Hairlines |
| `--border-strong` | `rgba(28,27,22,0.28)` | Emphasis dividers |

## Type

- **Instrument Serif** — display / headlines only (incl. italic)
- **Source Sans 3** — body, labels, buttons (400 / 500 / 600)
- **JetBrains Mono** — addresses, ENS, hashes, timeline dates (400 / 500)

## Layout

- Content max: `1120px` (home), `880px` (profile), `760px` (hero text)
- Nav: `28px` / `56px` (mobile `24px` sides)
- Breakpoint: `720px`
- Radius: `10px` cards/inputs, `6–8px` buttons
